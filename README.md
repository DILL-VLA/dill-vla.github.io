# DILL project website

Project page for **Disentangling Spurious Correlations in Vision-Language-Action Models via Predicting Domain-Invariant Latent Lookahead**.

Website: https://dill-vla.github.io/

The initial page preserves the HTML draft from the shared project conversation. It includes the paper title, authors, affiliations, and five supplied author links. Research materials and paper/code links will be added when available.

## Editing and publishing

Edit `index.html` and commit to `main`. GitHub Pages serves this static site from the root of `main`; no build step or dependencies are required.
